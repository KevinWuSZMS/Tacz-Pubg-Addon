# NeoForge 1.21.1 学习与 TaCZ PUBG 附属工作区

## Git 仓库范围

本仓库从现有开发工作区建立源码基线，文件保持原位。Git 跟踪模组 Java、测试代码、元数据、玩法配置、语言与着色器、自写开发工具和维护文档；本地运行实例、存档、下载包、备份、原始素材和生成输出不进入版本历史。

构建模组只需 `neoforge-1.21.1/` 目录及 Java 21。在该目录运行 `.\\gradlew.bat jar`（Linux/macOS：`./gradlew jar`），成品在 `build/libs/`。首次构建需要下载 Gradle 和标准 NeoForge 工具链；项目专用编译库已固定在 `libs/`，不打入成品。最终贴图、网格、模型等随源代码发布，无需游戏实例、原稿或检查用快照。完整开发检查仍需要本地 `test-inputs/` 和部分运行组件。GitHub Actions 在 main 推送后构建并提供成品下载。

边界、依赖与恢复项见 [仓库边界说明](docs/repository/BOUNDARY.md)、[依赖清单](docs/repository/dependencies.json)和[资源来源清单](docs/repository/asset-provenance.json)。本模组采用 [Apache License 2.0](LICENSE)；第三方素材与依赖保留各自的许可。

本工作区包含离线教程、可构建的 Minecraft 1.21.1 开发项目，以及 **TaCZ PUBG Addon**（`tacz_pubg`）。源码包名仍为 `com.example.examplemod`；旧模板方块、食物与 `examplemod` 注册内容已移除，当前实践入口是物资区域标记、配置、生成与地图工具。

当前物资配置已取消组合模板。每个 `kind + id` 只保留一条独立物品设置；自动纳入 TaCZ 的全部有效枪械、弹药和配件，辅助制造台、靶和箱不进入初始物资池；条目数量没有128个的业务上限，仍有单次传输与文件体积保护。独立弹药默认权重及类别概率均为0，逐枪配弹仍独立进行。

主物品使用两级概率：先按实验开关筛选并计算单品有效权重，再抽类别，最后按该池内的正有效权重抽物品。10类的项目建议初始比例为：枪械40%、弹药0%、瞄具15%、弹匣15%、枪口10%、握把8%、枪托5%、激光2%、其他配件0%、普通物品5%，合计100%。这些是本项目初始建议，不是PUBG官方绝对比例；枪型数量增加不会自动抬高枪械类别占比。

`/pubgdebug config` 沿用已批准的 HTML 原型布局，顶部统一为“基础设置 / 原始/实验性 / 创建地图 / 创建游戏”。基础设置集中编辑类别比例、池内物品权重和逐枪配弹，并显示有效权重、池内及总体占比；通用生成参数也在此入口。原生界面使用 Minecraft 原生控件、物品图标与实际服务器保存逻辑，独立 HTML 仍只作为讨论原型。空池概率只在其他正概率非空池间重分配，概率0的类别不会复活；编辑中暂未凑满100%可切页，保存时必须合计100%。`schemaVersion: 8` 支持逐枪 `ammoSupply`，保留schema6的完整10键 `categoryProbabilities`；旧配置先备份再迁移，保留原权重、实验开关和General配弹／专用配件参数。配套弹药与专用配件额外生成，不占主抽样类别概率或密度。

分类刷新调配可参考官方 [PUBG16.2](https://www.pubg.com/en/news/1717)（普通Erangel弹匣约−28%、瞄具约+75%）与 [22.2](https://pubg.com/en/news/4555)（指定霰弹枪及弹药在普通／排位约−30%／−20%）。它们记录的是相对改动，不能证明内部抽样算法、本项目绝对比例或多数游戏的通用实现。

“创建地图”直接在 Xaero 真实地形上绘制矩形、圈与航线，显示选点和边界坐标；手动坐标表单在开发者模式。“创建游戏”选择已保存地图，按“地图→规则→人员”三步创建；规则中独立填写1–100总人数和单/双/四人队，支持命名保存及预选加载，人员步骤编队并开始。假人空装搜集物资，参赛者开始后切为冒险模式。编队随主世界 `data/tacz_pubg_lobbies.dat`、规则随 `data/tacz_pubg_matches.dat` 保存，地图及物资配置各自独立；开局冻结规则，结束后再修改，重启不自动续局。项目短局9阶段共14分30秒，另准备30秒；“PUBG排位计时参考”仅采用官方 SUPER v6.0.3 的30分10秒计时，半径、随机圆心和 MC HP 伤害仍是项目建议。轰炸弹种、伤害、衰减、地形作用与显示配色集中在基础设置；完整官方来源、普通/排位差别与验证边界见[对局说明](docs/蓝圈对局命令.md)。

先按面积、系数和密度生成全部主物品，再逐枪补充弹药。在“基础设置”选择枪后编辑“配弹设置”：每枪三个配弹方案，只抽一次；默认全用自己当前的弹药、分别1／2／3组。步枪／冲锋枪／机枪的方案概率30%／60%／10%，其他枪类60%／30%／10%；每组默认30发（步枪／冲锋枪／机枪）、10发（霰弹）、15发（狙击／DMR／手枪）、1发（火箭）或3发（榴弹）。每方案可独立修改弹种、组数和概率，每组发数也可逐枪修改。跟随弹种支持子弹实验切换，显式ID保持选择。配弹默认距枪1～1.5格，通用设置可调整；重载未完成或失败时暂停生成。配弹不占主物品密度，所有物品独立采用连续 `[0°,360°)` 随机水平朝向。

## 基础设置中的轰炸与配色

`基础设置 → 轰炸弹 / 显示配色 / 重武器` 集中编辑每发轰炸弹的弹种、中心伤害、爆炸伤害半径、边缘伤害比例和方块破坏开关。默认 `tacz:rpg_rocket`、10 HP、4 格、边缘 0%、保留方块。弹丸默认在世界限高以下最高空气方块生成，0初速垂直自由下落；生成Y和可穿过方块列表可编辑。重武器逐枪展示当前加载的伤害、实体半径、地形爆破强度，并独立切换地形破坏。启用“原始/实验性 → 平衡调整 → 实验性”后，13把重武器采用逐枪R/p/q截断幂伤害曲线；初始R保留批准的8–12格。榴弹地形强度统一为普通苦力怕的3，火箭筒保留独立强度。地图中的轰炸圆决定落点区域，每个区域保留独立的每分钟发数。

每局开始时固定轰炸弹性质，准备结束进入战斗后发射，暂停与结束时清理在途弹。已加载区块中的真实 TaCZ 火箭弹参与碰撞，爆炸伤害按距离线性衰减，并保留原版遮挡、护甲和伤害事件。统一配色包含安全区、蓝圈、轰炸区、闪电、边界、航线及四项不透明度；开启统一配色后，保存即可同步显示。

## 启动与构建

双击 `scripts/run-client.bat` 自行启动开发客户端。构建使用 `scripts/build.bat`，或在 `neoforge-1.21.1` 目录执行：

```powershell
.\gradlew.bat build
```

产物为 `neoforge-1.21.1/build/libs/tacz_pubg-1.0.0.jar`。开发实例直接加载源码编译结果，不要把该 JAR 再放入同一个开发实例的 `run/mods`。外部 Java 模组放在 `run/mods/`，TaCZ 枪包放在 `run/tacz/`，光影放在 `run/shaderpacks/`。

**按用户要求，后续默认只做构建、依赖和文件检查，不主动启动客户端或服务器验证游戏是否能打开。** 历史启动日志保留原样，不代表之后新增功能已经完成游戏内验证。

IDE 打开 `neoforge-1.21.1` 并按 Gradle 项目导入，Project SDK 与 Gradle JVM 使用 JDK 21。VS Code 工作区设置已指定 JDK；其 Java 扩展语言服务器自带的 Java 25 可保留。旧工具链诊断可通过 **Java: Reload Projects** 重新加载。

## 开始阅读和编辑

- `src/main/java/com/example/examplemod/ExampleMod.java`：当前模组注册、网络、事件与服务入口。
- `ExampleModClient.java`：客户端渲染、界面与键位注册。
- `spawn/`：人工地板标记、稳定区域及覆盖层。
- `lootconfig/`：物品目录、独立概率配置、搜索与界面。
- `gunbalance/`：枪械默认／研究方案、重载时参数转换和 TaCZ 原生同步。
- `lootspawn/`：生成、配弹、地面物资展示、选择与拾取。
- `zones/`、`backup/`：地图与圈定义、备份复原。
- `src/main/resources/assets/tacz_pubg/`：当前模组名称、提示与工具资源。
- `minecraft-sources/`：已展开的 Minecraft 与 NeoForge 源码，仅用于阅读，不参与重复编译。

在允许作弊的创造模式世界中取得标记棒：

```mcfunction
/give @s tacz_pubg:item_spawn_area_stick
/give @s tacz_pubg:pubg_config_map
/pubgdebug config
```

配置地图为附魔已使用地图样式，右键打开 `/pubgdebug config` 界面，仍需 OP。“创建地图”直接使用 Xaero 原生地形、缩放和平移，拖拽创建/调整，服务器确认保存后可用于“创建游戏”。赛制在“创建游戏”中单独保存。配置子页更改后右下出现“保存配置”，成功确认后隐藏。四个入口切换时保留各自草稿；真正关闭、切换编辑对象或放弃前会处理未保存内容。

主手拿棒，左键地板设第一角、右键同层地板设第二角。对空气左键清临时选区，右键保存，Shift+右键擦除框内标记；三个快捷操作可以修改键位。保存后白线立即消失，蓝覆盖保留。配置保存后，使用 `/pubgdebug itemRespawn` 刷新全存档所有维度的已标记区域。空手指向本附属已落地物资，按 F 拾取。TaCZ 枪械、弹药、配件及已保存概率列表中的普通物品/方块抛出后不自旋，玩家主动丢弃时采用视角 ±15°，空中保留原版 `minecraft:item` 运动，真实落地后转为 `tacz_pubg:ground_loot`。所有概率列表物品抛出和落地均沿用原生掉落物大小，不再额外乘薄片或图标大小系数。地面载体恢复 0.22×0.13 格小碰撞箱，允许模型边缘局部穿模；落地停止、支撑移除后继续下落。目录外其他物品保留原行为。转换品不会被 `itemRespawn` 清理。

Java 修改通常需要重新启动客户端；JSON 资源可按适用类型通过 F3+T 或 `/reload` 重载。重新导出阅读源码可使用 `scripts/Export-MinecraftSources.ps1 -Destination <新目录>`。

`/pubgdebug` 的全部子命令要求权限等级 2（标准 OP 管理权限）；配置保存等管理请求也在服务端重新检查权限。在 `config → 原始/实验性` 分别选择“初始”或“实验性调整”，点击“保存全部”后等待应用完成提示。平衡调整、瞄具、子弹独立生效；平衡实验保留既有控制缩放和每发真实峰值的持久后坐力，新增批准的枪类伤害、距离衰减、瞄准／腰射散布、开镜时间和射速上限，配合现实参考初速、下坠与速度衰减。现实弹道抵消 TaCZ 公共弹速倍数一次，取消同枪不同射击模式的弹速增量，保留其他模式属性。子弹实验合并补给引用，不改变弹道或清空枪内子弹；旧背包弹药不会自动转换。弹匣实验按逐枪供弹条件开放新九种配件；快速／扩容／快扩对应等级1／2／3，快速与快扩另加换弹加速。瞄具／弹匣实验分别只生成选定经典九镜／新九弹匣；子弹实验只保留18种批准独立供弹，激光实验只保留选定CBRG激光。枪口、握把、枪托实验按有效支持数降权，支持不超过当前枪数10%的专用件权重至多0.01，并可随兼容枪配发；概率a和种类b在“基础设置”的通用生成参数中调整。界面保留基础权重并显示有效权重，切回初始可恢复。设置随存档保存，有效设置切换通过资源重载生效，不改原枪包文件。通用设置中的“玩家与标靶可见距离”单独保存，默认均为 512 格，范围 16～1024 格。

## 本机设置与历史记录

玩家可见文案集中在 `neoforge-1.21.1/src/main/resources/assets/tacz_pubg/lang/zh_cn.json` 和 `en_us.json`，使用可读的英文语义 key；中文变体回退到中文，其他语言默认英文。界面布局仍在 Java 中，服务端反馈保留翻译引用，由各客户端选择语言。修改、变量占位符和新增 key 的步骤见 [本地化维护说明](docs/本地化维护说明.md)，使用位置可查 [key 索引](docs/localization-key-usage.json)。

项目通过 `.jdk-tmp` 处理本机 Windows UNIX socket 临时目录兼容问题。JDK 绝对路径与本地代理 `127.0.0.1:9674` 配置在 `gradle.properties`、wrapper 及工作区设置中；移动工作区或更换代理时需同步修改，游戏本地连接绕过代理。配置说明见 [Java 21 网络属性](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/net/doc-files/net-properties.html)。

指定 HMCL 原实例仅作为复制来源，原有安装与内容保持不变。键位、灵敏度、光影、优化组件、Carpet、Voxy、Xaero 与 JEI 的固定版本和部署证据分别保存在上面的专项记录中。`downloads/` 保留原始下载，`logs/` 保留历史构建、启动与检查记录，`logs/source-backups/` 保留修改前源码。最早的 MDK 部署记录使用 `examplemod` 名称和示例物品，属于历史状态，不适用于当前模组。
