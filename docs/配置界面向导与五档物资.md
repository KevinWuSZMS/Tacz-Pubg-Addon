# 配置界面向导与五档物资

本次接续 `tacz pubg addon (3)` 中 2026-10-19 20:50 的界面要求，以及 21:14、21:19 重复提交的确认和重武器要求。沿用 `/pubgdebug config` 与配置地图物品入口。

## 配置与地图

- 配置按钮、面板和输入框采用统一纯色自绘。更改后右下出现“保存配置”，成功确认后隐藏；地图保存成功返回地图列表。
- 地图列表提供新建、编辑、删除。地图编辑独立展示；属性面板跟随所选对象，蓝圈伤害属于安全区。
- 普通模式绘制地图边界和航线；开发者模式开放手绘安全区、轰炸区与精确坐标。拖动矩形时按 Shift 保持正方形。
- 地图显示已标记物资地板。相同 X/Z、不同 Y 才累计楼层；单层使用档位原色，达到 n 层时线性变黑。同一 Y 重叠不增加层数。颜色页可调整五档颜色和 n（2–256，默认 5）。
- 配置编辑不再周期性重新读取和重建表单。地图保存/删除使建局地图缓存失效，返回时再读取；运行状态更新保留当前输入和滚动位置。

## 三步建局

1. **选择地图**：只选择已保存地图，不在此跳转编辑。
2. **对局规则**：单独填写总人数 1–100（默认仍 20），选择单/双/四人队，配置缩圈和每局轰炸。规则可命名保存、预选加载；预设只把规则读入草稿，保存后才作用于下一局。第二步起隐藏主导航。
3. **人员设置**：添加、移除与归队真人/假人，支持填充到规则总人数。所有假人空装进入，通过地面物资搜集枪弹。最后一步按钮为“开始对局”。

地图只保存边界和航线也可建局：开局按短边半长生成初始安全区，后续按规则缩圈；没有手绘轰炸区时按边界生成轰炸区域。开发者手绘圈可保留，轰炸关闭则不发射。自动胜负模式仍需要至少两队；1 人练习关闭自动胜负。

房主可保持当前游戏模式完成建局；提交的参赛者在真正开局时切为冒险模式，结束时通过原模式标记恢复。修改和控制请求继续在服务端校验 OP 2 级权限、版本号和成员合法性。规则、编队和运行状态各自独立，重启不自动续局。

## 重武器

榴弹地形爆破强度统一为 3，对应普通苦力怕；火箭筒保持独立地形强度。实验性平衡的实体爆炸伤害使用

`D(r) = Dmax × [1 − (r/R)^p]^q`，`r >= R` 时为 0。

每枪可单独设置 R（0–128 格，不含 0），p、q 使用 1–2 滑块。配置在发射时冻结，保留原生遮挡、护甲、伤害事件和击退链路；切回初始平衡恢复原生伤害曲线。13 把重武器已逐项查询，可靠来源不能确定硬截断半径或 p/q，因此保留已批准 R/Dmax，明确把曲线形状标为游戏估计。逐枪来源和边界见 [研究记录](gun-balance/heavy-curve-research.json)。
