# TaCZ PUBG 附属：物资地板标记工具

Minecraft 1.21.1 / NeoForge 21.1.259，更新：2026-10-17。模组为 **TaCZ PUBG Addon**，ID `tacz_pubg`。地板是否在房屋室内仍由作者人工核验；工具记录批准位置，不自动证明建筑室内。

## 操作流程

需要权限等级 2，在允许作弊的世界中取得工具：

```mcfunction
/give @s tacz_pubg:item_spawn_area_stick
```

工具类为 `ItemSpawnAreaStick`，使用木棍材质和附魔辉光。采用 [WorldEdit 两角选区](https://worldedit.enginehub.org/en/latest/usage/regions/selections/)的习惯，并参考 [Litematica 多子区域预览](https://github.com/maruohon/litematica/wiki/Multi%E2%80%90Region-Area-Selections-%28pre%E2%80%90mod%E2%80%90rewrite%29)。无需安装这两个模组。

1. 主手拿棒，左键地板第一角，右键同一方块 Y 的地板第二角。
2. 查看当前临时选区：未批准部分为青色，已批准部分仍为蓝色，白线只描临时选区外围，不画每格内部白网格。
3. 确认室内范围后，**对空气或未命中方块时右键保存**；也可用 `/pubgdebug area add`。
4. 保存成功立即清空临时两角和白线，批准地板的蓝色覆盖保留。

空气快捷操作：

| 默认操作 | 作用 |
| --- | --- |
| 左键 | 清空当前临时选区，不删除已保存地板 |
| 右键 | 保存当前选区的合格地板 |
| Shift+右键 | 擦除当前临时选区范围内已经保存的地板；框外部分保留 |

以上三项可在控制设置的“物资区域编辑”分类修改键位，HUD 显示实际绑定。快捷操作只在持棒且未命中方块时启用；命中方块时保留左键第一角、右键第二角。擦除成功也清临时选区和白线，不会把碰到的整个区域编号对应地板全部删除；删除连接地板后按区域分裂规则处理。

左右选角不会挖地板或打开箱子、门。副手持棒也强制显示附近区域；选两角建议主手拿棒，避免其他主手物品先消费交互。单格选区对同一地板左键、右键即可。坐标取地板方块本身，两角都包含；例如 X=10..12、Z=20..23 为 12 格。临时两角同层，不拉三维盒子；多层逐层批准。

## 命令保留

```mcfunction
/pubgdebug showItemSpawnArea true
/pubgdebug showItemSpawnArea false
/pubgdebug area add
/pubgdebug area remove
/pubgdebug area clearSelection
/pubgdebug area info
/pubgdebug area list
/pubgdebug area list 2
/pubgdebug area info 17
```

`add` 保存后立即清临时选区；`remove` 删除当前框与已批准集合的交集，成功后也清临时选区，不改变真实方块。即使旧位置现在已不是合格地板，也能删除旧记录。`clearSelection` 只清自己的临时两角。

`area info <编号>` 支持 Tab 补全已有区域，候选提示包含维度、面积、稀有系数和范围坐标，不需要凭记忆输入编号。

清空当前维度全部批准地板仍需显式命令：

```mcfunction
/pubgdebug area clear
/pubgdebug area clear confirm
```

其他维度保留。添加、擦除、清空维度要求持棒；信息、显示偏好和清临时选区仍要求作者权限。每次矩形最多 4096 格，每维度最多 65,536 格，全存档最多 262,144 格；这些地板安全限制与物品目录取消 128 条上限是不同事情。

## 覆盖层与光影路径

显示偏好仅对执行者生效并随世界保存。`true` 时不持棒也显示附近蓝覆盖；`false` 时收棒隐藏。主手或副手持棒始终强制显示，服务端仍校验权限。

蓝色表示已批准地板，青色表示临时选区中尚未批准的表面；白线只属于临时选区。保存、擦除或清选区后，白线完全消失。多个相邻地板共用边自动抵消，不再出现交叉网格；已有蓝区没有常驻白网格。

覆盖层沿真实碰撞顶面绘制，正常遮挡，约 64 格范围内显示，只使用客户端已加载区块。表面缓存分批更新，不每帧扫描全图。

渲染已从粒子阶段/粒子目标改为 **`RenderLevelStageEvent.AFTER_LEVEL` + 主渲染目标**。显式使用当前帧相机位置、view/projection 矩阵，先以 double 精度减相机坐标，再转顶点，并加表面高度和多边形偏移；不继承粒子阶段的可变渲染状态。这样在 Iris 完成最终合成之后画编辑覆盖，减少覆盖被光影 final pass 替换、视线高度变化时的深度闪烁等问题。

依据为本机对应版本 Minecraft/NeoForge 源码和 Iris 1.8.12 JAR 静态检查：GameRenderer 在 LevelRenderer 返回后派发 AFTER_LEVEL，而 Iris 在 LevelRenderer 返回前完成 `finalizeLevelRendering`。相关官方源码：[NeoForge RenderLevelStageEvent](https://github.com/NeoForged/NeoForge/blob/1.21.1/src/main/java/net/neoforged/neoforge/client/event/RenderLevelStageEvent.java)、[Iris 1.21.1 MixinLevelRenderer](https://github.com/IrisShaders/Iris/blob/1.21.1/common/src/main/java/net/irisshaders/iris/mixin/MixinLevelRenderer.java)、[IrisRenderingPipeline](https://github.com/IrisShaders/Iris/blob/1.21.1/common/src/main/java/net/irisshaders/iris/pipeline/IrisRenderingPipeline.java)。这是代码路径修复，未启动游戏逐一验收全部光影。

## 地板验证和持久区域

保存前服务器检查权限、持棒、两角、范围、世界边界、已加载区块和真实地板几何。包含未加载区块时整次拒绝，不临时加载它们。地板无流体、形状位于本格、顶面投影完整覆盖 X/Z，并在每片顶面保留至少 0.25 格净空；完整方块、半砖和普通楼梯可用，空气和突出格外的栅栏等不算地板。楼梯覆盖沿真实高低踏面绘制。

最终区域由批准地板集合组成，可通过多个矩形形成 L 形、带孔形或多层形，不填满外接矩形。以下连接自动合并：同 Y 水平四邻接共享边；或同 X/Z 上下相差 1～10 格。只连接已经人工批准的地板，不搜索并批准新楼层，也不跨维度；角点接触和错位楼层不自动连接。

连接可传递，例如 Y=64、72、80 的重叠楼层可归一块。合并保留最早编号及其稀有系数；分裂时原锚点所在部分保号，其他部分获新号并继承系数；锚点已删除则按确定性坐标顺序保留一块。删除后编号不复用。完整规则见[非矩形区域说明](非矩形区域与面积密度刷新.md)。

面积按去重地板数量计 1㎡/格，多层累加。预计主物品数为有效面积 × 稀有系数 × 密度，小数概率取整，默认每 10㎡ 一个主物品。各主物品按唯一条目的独立权重抽取；生成结束再给枪配弹，配套弹药不占密度。详见[物品配置](枪组配置与全图刷新.md)。

## 数据、网络和代码

批准地板、区域编号、形状、锚点、稀有系数和个人显示偏好保存在主世界 `data/tacz_pubg_spawn_areas.dat`，随正常保存写入。不要手工改压缩 DAT。临时两角按玩家隔离，离线或换维度时清除；批准区域是共享数据，编辑者立即同步，其他订阅作者按预算接收附近更新。

| 类 | 职责 |
| --- | --- |
| `SpawnAreaService` | 命令、临时会话、服务端校验、保存与立即清选区 |
| `SpawnAreaSavedData` / `SpawnRegionTopology` | 逐格形状、稳定编号、合并分裂和系数 |
| `SpawnFloorGeometry` | 真实碰撞顶面和净空 |
| `SpawnFloorBoundary` | 抵消共面共享边，生成外围线段 |
| `SpawnAreaPayloads` | S2C 附近快照、C2S 有界工具操作码；不接受客户端任意地板列表 |
| `SpawnAreaClient` / `SpawnAreaClientState` | AFTER_LEVEL 覆盖、矩阵、表面缓存与 HUD |
| `SpawnAreaKeys` | 可重绑空气操作，按客户端 tick 消费键位 |
| `SpawnRegionConfigPayloads` / `SpawnRegionConfigScreen` | 区域摘要及稀有系数独立保存 |

源码在 `src/main/java/com/example/examplemod/spawn/`，工具资源在 `assets/tacz_pubg/`。Java 包名保留旧学习路径，旧模板 example 方块、食物与注册资源已删除。网络、存档和键位分别遵循 [Payload](https://docs.neoforged.net/docs/1.21.1/networking/payload/)、[SavedData](https://docs.neoforged.net/docs/1.21.1/datastorage/saveddata/) 和[Key Mappings](https://docs.neoforged.net/docs/1.21.1/misc/keymappings/)入口。

边界算法已通过 1,000 次随机形状周长检查，并加入相邻格、凹形、部分边、楼层与孔洞的回归检查。本轮统一构建结果见[更新说明](物品生成与交互更新说明.md)；未启动客户端或服务器进行画面测试。
