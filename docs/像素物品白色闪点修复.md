# 像素物品白色闪点修复

截图中的白点与碎白线符合像素网格 T 接点在浮点投影下出现细缝、再被原版物资发光描边放大的表现。关闭光影仍出现，与共用网格及描边流程相符。已抽查医疗箱、急救包、一级甲、一级头、烟雾弹，实际贴图区域均为完全不透明，没有透明贴图针孔；地面物品流程也没有重复绘制模型。

20 件已接入的真实源像素模型现保留原有所有 `elements`、显示倍率、PNG、萌趣模型与开伞绳索 LOD，仅新增缓存的共形网格数据。每个长边上原有的中间顶点都成为真正的共边顶点；只处理存在接点的面，并优先把相邻三角重新合成四边形。像素模型使用明确的裁切渲染层，避免默认透明混合层。

固定密度 36 及原有作者面预算不变，修复开销另列：总计 26,527 个原四边形变为 37,599 个 GPU 四边形，增加 41.739%。医疗箱为 736 → 1,114，急救包为 769 → 1,159；最高的二级头为 3,484 → 4,813。没有为控制面数而降低密度或更改轮廓。

离线检查覆盖全部 69,784 个有效三角形的实际渲染边（含内部对角线），剩余 T 接点为 0；原有位置、面范围覆盖、面积、朝向和 UV 仿射映射均保留。16 项 Python 回归检查通过。安装备份和验证报告位于 `model-workflows/output/pixel_seam_repair/`，备份目录记录在 `installation.json`。这些是离线几何验证，不代表已在游戏中验证移动视角或所有光影组合。
