# 开发客户端启动与模组兼容说明

项目：`D:\HMCL-3.9.1\neoforge-mod-development\neoforge-1.21.1`。更新：2026-10-17。

## 自行启动

双击 [run-client.bat](../scripts/run-client.bat)，或在项目目录执行：

```powershell
.\gradlew.bat runClient
```

脚本会编译当前代码并启动开发客户端，无需先打包自己的模组，也无需通过 HMCL。修改 Java 后通常关闭客户端再重新启动。按用户要求，助手默认只做构建、文件和依赖检查，不主动启动游戏验证。

当前自己的模组是 **TaCZ PUBG Addon**，ID `tacz_pubg`。`build.gradle` 的 `neoForge.mods` 直接加载 `sourceSets.main` 编译后的类及资源，因此不需要在开发实例的 `mods` 放一份自己的 JAR。不要把 `build/libs/tacz_pubg-1.0.0.jar` 再复制进去导致重复加载；产物用于另一个普通 Minecraft 1.21.1 / NeoForge 21.1.259 实例。

源码包名 `com.example.examplemod` 仅为沿用的学习项目路径，不代表当前注册 ID。旧模板食物、方块和对应资源已移除，不再通过 example 命令体验当前功能。用 `/give @s tacz_pubg:item_spawn_area_stick` 和 `/pubgdebug config` 开始实践，见[物品交互更新](物品生成与交互更新说明.md)。

## 文件应该放在哪里

| 内容 | 开发实例路径 |
| --- | --- |
| 外部Java模组运行版JAR | `neoforge-1.21.1/run/mods/`，mods带s |
| TaCZ枪包ZIP或资源文件夹 | `neoforge-1.21.1/run/tacz/` |
| 光影包 | `neoforge-1.21.1/run/shaderpacks/` |
| 当前游戏日志 | `neoforge-1.21.1/run/logs/latest.log` |
| 崩溃报告 | `neoforge-1.21.1/run/crash-reports/` |

外部模组必须选适用于 Minecraft 1.21.1 / NeoForge 的构建并满足声明依赖；`-sources.jar` 不放运行目录。原始下载和元数据保存在 `downloads/`。

## 当前TaCZ与编译依赖

安装 [MUKSC 的非官方移植](https://modrinth.com/mod/tacz-1.21.1)，版本 [1.1.8-hotfix-r7](https://modrinth.com/mod/tacz-1.21.1/version/62q6mB5Q)，项目 ID `OypNE65K`、版本 ID `62q6mB5Q`。运行文件为 `run/mods/tacz-neoforge-1.21.1-1.1.8-hotfix-r7.jar`，原下载阶段核对 SHA-512 和 NeoForge 元数据；证据位于 `downloads/tacz/`。

当前工程已配置匹配 r7 的编译依赖，并在模组元数据声明 TaCZ 必需依赖，运行沿用 `run/mods` 的单份JAR。不能只在mods放JAR就认为另一个新工程的IDE自动有API；另开工程仍需配置对应编译依赖和元数据。`docs/TaCZ-1.21.1-API源码/` 是只读参考材料，不直接编进附属。

枪包和 Java 附属不同：枪包主要是模型、动画、JSON、Lua，TaCZ 读取 `run/tacz`；Java 附属是NeoForge模组，放mods并需要Java版本/依赖匹配。TaCZ 共用通用枪Item，通过GunId区分枪型，详见[注册与制作说明](TaCZ枪械注册与制作说明.md)。

## 版本与枪包转换

离线官方 Wiki 对应原 Forge 1.20.1 / TaCZ 1.1.4 资源体系，当前实际运行是NeoForge 1.21.1 r7。资源结构可参考教程，具体接口、配方和行为以本机匹配源码为准；旧1.20.1世界不能直接当作当前移植版兼容世界。

当前 PUBG 枪包部署已经安装 [TaCZ Pack Upgrader](https://modrinth.com/mod/tacz-pack-upgrader)，并保存转换后的包及作者资源。它适配枪包，不能自动把旧 Java 模组移植到 NeoForge 1.21.1。完整版本、文件、备份、转换和缺失枪械见[PUBG枪包部署记录](PUBG枪包部署与缺失对照.md)。

加/改枪包后，除重新加载TaCZ目录外，还要更新本附属的服务器数值模型占地清单，见[地面展示说明](地面枪弹平放与弹匣分组.md)。

## 用户自行兼容观察的范围

正常启动只能证明当次加载成功，不能证明所有玩法、光影、资源、联机和物资拾取都兼容。用户可自行在测试世界检查目标场景：编辑地板、打开物品配置、保存刷新、观察不同模型和光影、空手F拾取；修改前保存或备份自己的测试世界。

独立服务器可通过 [run-server.bat](../scripts/run-server.bat) 启动，再连接 `127.0.0.1:25565`；纯客户端模组遵守各自发布说明。客户端和独立服务器目前共用run目录，避免同时使用同一世界。
