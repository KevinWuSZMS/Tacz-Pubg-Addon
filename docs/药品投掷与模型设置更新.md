# 药品、投掷物和模型设置更新

本轮保留此前接入的源模型，继续修复使用规则、效果、物品比例和开发实例崩溃。

## 药品与投掷物

绷带、急救包在生命值达到 75% 时，客户端与服务器都拒绝开始使用；使用中由其他来源恢复到上限，会停止且不扣药。医疗箱、逐步恢复预算、使用时长、能量上限及取消条件按[规则说明](药品使用规则修复.md)执行。药品在对局外保留完整治疗与能量效果，普通世界能量独立保存和同步；不会借此打开比赛 HUD 或绕过比赛暂停、淘汰限制。

轨迹预览按本帧眼位和当前视角生成，删除原先 1 度/33 毫秒的跳变式更新，使用同帧摄像机矩阵，并处理轨迹与视线共线时的线宽退化。预览与真实弹体共用发射和 LR 碰撞规则；变更重力、反弹等设置会同时影响两者。

PUBG 投掷物保持自己的物品 ID，第一人称使用 LR 的模型展示、动画状态机及音效。烟雾弹直接使用 LR 烟雾实体的实现，震爆弹直接调用 LR 的致盲、失聪算法与效果，旧自绘烟体、白屏和声音过滤通路已移除。对局外可以使用投掷物并保留效果。温雷仍采用既有 R 操作；最后一颗被提交后，原生动画保留视觉显示，但不把已消耗物品放回物品栏。

`基础设置 → 投掷物` 提供逐种编辑：列出本模组的七类投掷物，以及 LR 当前加载的全部投掷物索引。通用和专属属性递归列出，未知扩展属性也可从完整 JSON 编辑。属性随存档保存，经管理员权限、数值与类型、完整 LR 数据解析和版本检查后同步；不会改动原枪包数据文件。不同实现只列出实际会使用的字段，原生 LR 项保留完整专属数据。

## 模型与比例

- 新增烟雾弹 `item_035_01` 的两种风格模型。
- 三级头盔的像素硬核模型分别采用 `item_027_02`、`item_027_03`、`item_027_04`，固定分辨率 36；现有萌趣世界头盔保留。
- 伞包改放护腿栏，与背包共用装备位置；不增加背包容量。实际伞包模型在背部显示，飞行标记、开伞检测、旧胸槽装备迁移、临时装备回收和原装备恢复一起更新。

已对 20 件有源模型的物资进行 C4D 世界边界、文档单位、归一化因子与最终展示尺寸比对。[完整比值表](../model-workflows/output/supply_size_audit/size-comparison.html)及[CSV](../model-workflows/output/supply_size_audit/size-comparison.csv)记录每件物品的三轴尺寸、旧/新尺寸和倍率。

C4D 的确保存 DocumentUnit。PUBG82 文档标注英寸，而 CharacterS 标注厘米；同一件一级甲在两个来源的几何数值几乎一致，直接按文档单位换算会产生 2.54 倍冲突。因此，不能把文档单位当作已证实的现实尺寸。此前每件都独立归一化到最长边 14，并使用相同掉落缩放，才是相对比例丢失的直接原因。

本轮保留同族原始数值比例，以明确标注的游戏展示校准值确定基础尺寸。医疗箱最长边由 43.75 厘米调整至约 68.95 厘米，急救包至约 51.92 厘米，保留两者源尺寸比；其他类别按各自基准校准。GUI 图标不因世界尺寸变小而难以辨认。源网格、纹理和原始 C4D 保持不变。

`其他设置 → 模型比例` 可逐物品输入 0.1–5 倍的掉落、穿戴倍率，分别保存萌趣世界与像素硬核的当前值和默认值。支持设为默认值、恢复当前风格默认值、恢复初始倍率 1；另一种风格的未保存草稿和默认值不受影响。详见[模型比例设置](模型比例设置.md)。
