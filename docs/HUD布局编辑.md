# 个人 HUD 布局

在正常游玩时按 **F8**，或从基础设置打开 HUD 布局编辑。编辑器使用当前窗口的实际尺寸，保留清晰的游戏场景与手臂，不添加背景模糊、黑底或全屏暗色遮罩。隐藏状态的 HUD 也会提供可拖动预览。

直接拖动组件即可调整位置；窗口缩放后，已调整的位置会按相对坐标保持在可见范围。重叠组件可用 Tab 或 PageUp / PageDown 轮选，方向键微调，Shift 加方向键每次移动 10 像素。

拖动界面仅在角落显示 ESC 提示。按 **ESC** 打开更改菜单：

- **保存并退出**：保存本机布局，再返回进入编辑器前的页面。
- **不保存并退出**：恢复进入编辑器时的布局，再返回原页面。
- **继续编辑**：关闭菜单，继续拖动。
- **恢复初始位置**：将草稿恢复为组件默认位置，继续编辑；选择保存后才会写入本机。

菜单也保持背景清晰。保存失败会保留当前草稿并在菜单中显示错误，可重试或不保存退出。由其他设置页面进入时，返回该页面会保留它尚未保存的内容。

布局写入客户端 `config/tacz_pubg-hud.json`。Xaero 小地图位置通过其原生设置保存；取消编辑会一并恢复，其他小地图设置不变。
