# 地图、安全区、蓝圈与轰炸区

适用：Minecraft 1.21.1、NeoForge 21.1.259、TaCZ PUBG Addon。更新日期：2026-10-19。

当前已实现地图和圈的**创建、原生 Xaero 图形化编辑、范围判断及存档保存**。`config → 创建地图` 绘制地图，`config → 创建游戏` 保存每地图赛制模板；明确开始后进入准备、阶段预警与收缩、终圈及胜负流程，`endMatch` 主动中止。轰炸区在战斗阶段按各自频率发射所选 TaCZ 火箭弹；弹丸性质与统一配色在基础设置编辑。完整参数与官方研究见[对局配置、缩圈与胜负](蓝圈对局命令.md)。

当前 Xaero 小地图/世界地图叠加、队友标记与蓝圈世界/屏幕效果，以及玩法缺口，见[地图叠加与 PUBG 玩法差距](地图叠加与PUBG玩法差距.md)。

## 概念与边界

| 概念 | 当前保存的信息 | 范围规则 |
| --- | --- | --- |
| 地图 `MapDefinition` | 编号、名称、维度、最小/最大 X/Z、初始安全区、静态预览蓝圈伤害、轰炸区列表、可选航线、配色与不透明度 | 当前维度的一块矩形，忽略高度；对局使用开局快照 |
| 圆 `Circle` | 中心 X/Z、半径 | 按水平距离判断，圆周上的点属于圆内 |
| 安全区 `SafeZone` | 一个圆 | 一张地图至多一个；必须明确创建 |
| 蓝圈/毒圈 `BlueZone` | 地图中的静态预览每秒伤害值 | 地图内、安全圆外的部分；开局后按当前收缩圆及赛制阶段伤害运行 |
| 轰炸区 `BombingZone` | 编号、落点圆、每分钟发数；历史伤害字段保留用于存档兼容 | 一张地图可有多个，弹丸性质来自基础设置 |
| 航线 `FlightPath` | 起点 X/Z、终点 X/Z | 一张地图至多一条；有方向的直线，两端均在地图内；仅显示与配置 |

这里的“地图”是对局的矩形场地定义。物资编辑棒登记的非矩形地板区域仍独立保存；创建地图不会自动登记地板，也不会改变已有物资区域。

地图使用**连续坐标边界**，先规范化两个角点的大小，再保存 `minX/minZ/maxX/maxZ`。不采用方块选区的 `+1` 扩张规则：从 `(0, 0)` 到 `(10, 10)` 的地图宽深都是 10 米，面积为 100㎡。边界本身包含在地图内，宽和深必须大于 0。

同一存档可以有多张地图，包括同一维度内的多张地图；每张地图保存自己的维度。**编辑选择**不会因玩家位置自动切换，使用明确的地图选择。跨维度切换后，原编辑选择仍保留；创建圆形区域或航线时会检查选中地图是否属于玩家当前维度。退出服务器后需重新选择。游玩叠加层的地图选择与编辑权限独立。

### 圆可越界，生效范围裁剪

安全区与轰炸区的圆心必须在所属地图内，但半径可以使圆超出矩形。实际范围始终取圆与地图的交集，不把地图外算入生效范围。

设玩家水平位置为 `P`，地图矩形为 `M`，安全圆为 `S`：

```text
安全区 = M ∩ S
蓝圈   = M \ S
轰炸区 = M ∩ 对应轰炸圆
```

还要同时匹配地图的维度。安全圆周属于安全区；地图外不属于这张地图的蓝圈或轰炸区。**没有安全区时，也没有蓝圈范围**，不会把整张地图默认判成毒圈。

以上范围规则同时用于显示与已开局的蓝圈伤害。未开局使用已保存的初始安全圆作配置预览，不扣血；开局后读取本局当前安全圆，不改写地图定义。

## 创建和选图命令

以下都属于 `/pubgdebug` 的子命令，需要玩家身份及权限等级 2。地图编号由存档分配，不需要自己指定。

先创建矩形地图，再创建所属安全区和轰炸区：

```mcfunction
/pubgdebug createMap -512 -512 512 512
/pubgdebug createSafeZone 0 0 400
/pubgdebug createBombingZone 120 -80 40
/pubgdebug createFlightPath -512 0 512 0
```

第一条在当前维度创建 X/Z 为 `[-512, 512] × [-512, 512]` 的地图，并自动选中它。第二条创建中心 `(0, 0)`、半径 400 米的安全区。第三条创建中心 `(120, -80)`、半径 40 米的轰炸区。第四条创建从西向东的航线，仅保存定义与显示，不启动飞机或跳伞。

完整参数形式：

```text
/pubgdebug createMap <x1> <z1> <x2> <z2>
/pubgdebug createSafeZone <centerX> <centerZ> <radius>
/pubgdebug createBombingZone <centerX> <centerZ> <radius>
/pubgdebug createFlightPath <startX> <startZ> <endX> <endZ>
/pubgdebug removeFlightPath
```

角点、中心与航线端点均使用 Minecraft 的二维 `Vec2` 坐标参数，**只输入 X Z，不输入 Y**。支持 `~` 相对坐标；不支持 `^` 局部坐标。原来的三维命令语法已停用。

例如，以当前水平位置为中心创建 128×128 米地图，或在当前位置创建轰炸区：

```mcfunction
/pubgdebug createMap ~-64 ~-64 ~64 ~64
/pubgdebug createBombingZone ~ ~ 24
```

坐标参数使用 `Vec2Argument.vec2(false)`，**整数坐标不会自动加 0.5**。例如中心参数 `10 20` 保存的中心就是 `(10, 20)`，而不是 `(10.5, 20.5)`。该原版类的 `Vec2.x` 对应世界 X，`Vec2.y` 对应世界 Z。

`createSafeZone` 不覆盖已有安全区；已有圆请在配置界面调整或移除后重建。`createBombingZone` 每次新增一个轰炸区。`createFlightPath` 不覆盖已有航线，已有航线在配置界面调整，或先用 `removeFlightPath` 移除后重建。航线两端必须在矩形地图内且不能重合。

查看与手动选图：

```mcfunction
/pubgdebug mapList
/pubgdebug mapSelect 1
/pubgdebug mapInfo
/pubgdebug mapInfo 1
```

`mapSelect <id>` 和 `mapInfo <id>` 支持 Tab 补全已有地图编号，候选提示包含地图名称和维度。坐标及新名称仍可自由输入，不限制为已有值。备份也提供按地图编号的补全入口，见[地图备份与复原](地图备份与复原.md)。

- `mapList`：列出全存档的地图编号、名称、维度、范围和圈数量。
- `mapSelect <编号>`：明确选中地图，编号支持命令补全。
- `mapInfo`：查看当前选择；加编号则查看指定地图，不隐式切换选择。
- 创建地图会自动选中新地图；在配置界面打开一张地图或成功保存后，也会选中该地图。

## 在 config 中创建和调整

执行 `/pubgdebug config`，点击第三个入口 **创建地图**。赛制模板与地图定义分别保存；第四个入口 **创建游戏** 使用已保存的地图。

默认新建或打开地图，直接进入 Xaero 原生图形编辑器。在实际地形上平移、缩放、框选地图边界、绘制安全圆/轰炸圆/航线，再选择对象调整。编辑区持续显示鼠标 X/Z、矩形边界与宽深，以及选中对象的坐标；侧栏显示名称和相关属性。小窗口可收起侧栏，侧栏点击不会触发底图绘制。保存需等待服务器确认；成功后才将地图交给“创建游戏”。

手动坐标输入收进 **开发者模式**。Xaero 暂不可用或地图属于其他维度时显示原因和重试入口，不把手工坐标表单当作默认编辑方式。以下参数页保留用于开发者的精确调整：

1. 地图列表：分页查看已有地图，点击某张地图进入编辑；点击“新建地图”可完全通过 GUI 创建，无需先执行命令。
2. **地图**：编辑名称和矩形最小/最大 X/Z。新地图属于当前维度，初始范围以玩家位置为中心、宽深各 128 米；已有地图的维度不能修改。删除地图只删除其定义和圈配置，不删除世界方块、实体或物资地板区域。
3. **安全/蓝圈**：创建或移除初始安全区，编辑中心 X/Z、半径及静态蓝圈预览伤害。创建时使用当前矩形草稿的中心初始化。实际对局伤害在对局阶段表编辑，地图静态值不覆盖阶段值。
4. **轰炸区**：新增、切换、移除多个圆；分别编辑中心、轰炸区半径和每分钟发数。弹种、伤害与爆炸伤害半径在基础设置编辑。新增圆默认位于当前矩形中心，初始半径由地图大小推导且不超过 32 米。
5. **航线**：创建、编辑、移除起点→终点直线。起终点均为 X/Z；默认由当前矩形西边中点通向东边中点。两端必须位于地图内，不启动飞机、跳伞或对局。
6. **颜色**：六种 RGB 色块/色板与六位十六进制输入；四类不透明度 0–100%，恢复默认只修改草稿，保存地图后同步。每张地图独立保存。
7. **地图编辑**：返回 Xaero 原生地形与样式，工具支持拖拽创建地图矩形、安全圆、轰炸圆、航线，选择/移动/手柄调整/删除和撤销重做。图形编辑与属性表共用当前草稿；应用并返回不等于服务器保存。详情见[原生编辑说明](地图叠加与PUBG玩法差距.md)。
8. 点击“保存地图”，等待服务器确认。这是单张地图的独立保存，不需要点击父页面的“保存全部”，也不会代替“保存对局”。

开发者参数表在小窗口按页显示，用“上一项页/下一项页”切换。没有显示在当前页的输入仍保留。数值无效时会保留原输入并给出原因，不会悄悄改写或丢弃。

地图页与父页面的物资配置各自保存。打开地图页会保留父页面当前物资草稿；保存地图不会提交独立物品概率、物资密度、配弹半径或区域稀有系数。返回后，如需提交物资修改，仍在相应页面单独保存。当前物资规则见[物品配置与全存档刷新](枪组配置与全图刷新.md)。

四入口之间切换可保留地图草稿；切换地图、真正关闭或重新加载前，有未保存的地图修改会明确处理。服务器检查权限、编号归属、坐标与圆心、数值上限、文档大小以及版本；他人或命令在编辑期间修改了地图数据，会拒绝旧版本提交并保留草稿。此时需要重新加载最新数据，再检查并修改。

## 默认参数与上限

这些是本模组保存的默认值，均可在地图/圈页面调整，不是对 PUBG 官方数值的声明。

| 属性 | 默认值 | 当前允许范围 |
| --- | --- | --- |
| 蓝圈每秒伤害 | `1 HP/秒` | `0–10000` |
| 每个轰炸区的导弹数量 | `60 次/分钟` | `0–6000` 的整数 |
| 单枚导弹的范围伤害 | `10 HP` | `0–10000` |
| 导弹爆炸半径 | `4 米` | 大于 `0`，不超过 `128` |
| 圆形区域半径 | 创建命令显式输入；GUI 按地图推导 | 大于 `0`，不超过 `60000000`；命令参数最小为 `0.000001` |

`2 HP = 1 颗心`。基础设置中的轰炸弹默认中心伤害相当于5颗心；实际蓝圈伤害由赛制的逐阶段 HP/秒决定，详情见[对局配置](蓝圈对局命令.md)。

全存档至多 **256 张地图**，每张地图至多 **32 个轰炸区**，每张地图至多一个安全区。地图名称最多 80 个字符，X/Z 坐标范围为 `-29999984–29999984`，单张地图 JSON 最多 24 KiB。地图和轰炸区的正编号由服务器分配；删除后不回收编号。

### 每发轰炸弹的性质

在“基础设置 → 轰炸弹 / 显示配色”编辑：弹种、中心伤害 0–10000 HP、爆炸伤害半径 (0,128] 格、边缘伤害比例 0–100%、方块破坏开关。默认使用 `tacz:rpg_rocket`，10 HP、4 格、边缘 0%，保留方块。当前目录还提供 `cib:80` 与 `suffuse:120mm`，选项跟随服务器实际加载的火箭筒资源。

爆炸伤害半径：每发轰炸弹造成伤害的距离范围。轰炸区半径：地图上选择轰炸落点的区域大小。落点从轰炸圆与地图矩形的交集中选取，发数使用各区的每分钟设置。

几何伤害 = 中心伤害 × [1 − (1 − 边缘比例) × 距离 / 爆炸伤害半径]。原版遮挡、护甲与伤害事件进一步参与结算。方块破坏开启时，地形作用按该爆炸球与地图范围裁剪，并保留原版方块抗性及事件。

每局开始时冻结轰炸弹性质，战斗阶段运行发射；准备、暂停和结束按对局状态管理在途弹。发射与爆炸使用已加载区块，每 tick 和在途数量均有固定预算。地图复原仍由独立的[地图备份与复原](地图备份与复原.md)执行。

### 显示配色

基础设置提供安全区、蓝圈、轰炸区、闪电、地图边界、航线六项 RGB，以及蓝圈地图、轰炸区地图、蓝圈世界幕、蓝圈屏幕四项不透明度。“统一配色”开启后应用于所有地图显示，保存后同步到各客户端；“各地图配色”保留地图原有样式。

## 对局模板与运行

`/pubgdebug startMatch [地图编号]`、`endMatch [地图编号]`、`matchInfo [地图编号]` 保留 OP 管理命令及地图编号补全。不填编号时使用已选地图。每局保存独立 UUID、不可变地图与赛制快照；运行中的地图及对应赛制模板先结束才能修改。创造/旁观免疫蓝圈，重叠蓝圈伤害取最大值。

地图定义负责矩形与初始安全圆，另存的对局模板负责人数、队伍、准备、断线宽限、胜负开关和1–16个圈阶段。阶段等待时显示目标圆，收缩时移动当前圆中心与半径，终圈后继续判断存活队伍与时间上限。模板保存于主世界 `data/tacz_pubg_matches.dat`；地图仍在 `data/tacz_pubg_maps.dat`，物资配置也独立保存。重启只保留模板，不恢复正在进行的比赛。

默认短局9阶段合计14分30秒，另外准备30秒。另一预设只参考 PUBG 官方 SUPER v6.0.3 的排位/电竞计时，合计30分10秒；圆心算法、半径与 Minecraft HP 伤害是项目建议。普通模式28分50秒、排位30分10秒以及42.3圈偏移变化不能混为一套通用参数。具体字段、默认表、资料日期和官方链接统一见[对局配置与官方研究](蓝圈对局命令.md#官方计时参考与项目边界)。

PUBG 官方遥测区分当前安全圈与预警圈，阶段字段包含延迟、预警、收缩、伤害、半径等。本项目参考这种阶段结构，没有把示例 JSON 或端游伤害单位当成 Minecraft 默认值。[官方遥测对象文档](https://documentation.pubg.com/en/telemetry-objects.html)

轰炸使用对局生命周期、真实 TaCZ 弹丸和原版爆炸遮挡。PUBG 的旧红区支持说明提供了危险区与建筑避难的概念参考。[官方红区说明](https://support.pubg.com/hc/en-us/articles/115004198974-What-is-the-red-zone)

## 弹丸生成高度与重武器

`基础设置 → 轰炸弹 / 显示配色 / 重武器` 提供三个设置页。轰炸弹“生成高度Y”默认“世界限高”，对应当前维度最高可建筑方块Y，也可填写固定整数Y。每次选中XZ后，从设定高度向下寻找最高空气方块，在方块中心以0初速生成弹丸，每tick按0.06格/tick²垂直加速。

弹丸连续检查经过的方块，首次接触列表外方块时爆炸。空气自动穿过；`passThroughBlocks` 保存最多256种可穿过的完整方块ID，支持图标选择和逐项添加、移除。默认列表为空。弹丸生成高度和列表随下一局开局快照采用。

“重武器”按枪显示弹种、近距直击伤害（中心伤害）、爆破伤害、实体伤害半径、地形爆破强度和当前资源地形开关。参数为当前已加载TaCZ数据在配件、倍率和护甲计算前的值。平衡实验按批准方案将实体伤害半径设置为8–12格、地形强度为5–6.5，强度6为末影水晶基准。每枪可单独切换地形破坏，下一次发射采用新设置；“恢复资源值”继承枪包原值。开启破坏同时遵循TaCZ服务器全局爆炸地形开关。设置保存于 `zoneSettings.heavyWeaponTerrain`，以枪械ID为键。
