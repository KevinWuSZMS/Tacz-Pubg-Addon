# HUD 默认布局重置与对齐

2026-10-22。对应用户07:10截图及“重置所有UI”要求。

## 已确认的差异与原因

- 小地图仍在左上：`run/config/xaerohud.txt` 保存了 `x=0;y=0;fromRight=false;fromBottom=false`。上一版为保留旧用户位置，只给全新Xaero配置应用右下默认，当前实例因此未迁移。此次明确重置全部UI，旧位置不再优先保留。
- 圈条在地图下面：旧布局发现顶部空间不足时主动放在地图下方。改成只使用地图上方的附属区域。
- 圈条与枪械栈可以各存独立绝对位置，导致地图移动后分离。改成同一地图锚点；圈条等宽贴上、枪械栈在左。
- Xaero的模块预留框包含透明留白。直接拿模块宽度会使圈条超过实际可见地图边框；新版按实际绘制缩放、边框样式与整数舍入求可见外框，不再使用模块预留宽度冒充地图宽。编辑器也不能因“界面打开时隐藏地图”而丢弃这个锚点。
- 生命条默认240 GUI像素，而原版快捷栏是182，宽约31.9%。状态行又按内容宽度绘制背景，三组边界没有统一。改成共享完整外框及原版整数居中方式。

## 新默认关系

- 小地图右下，圈信息位于地图正上方且与可见地图外框等宽；枪械图标栈固定在地图左侧。编辑地图组时共同移动。
- 底部状态行、能量条、生命条均为原版快捷栏宽182 GUI像素，左右边界为 `guiWidth/2−91` 和 `guiWidth/2+91`。本实例GUI倍率4，显示宽为728物理像素；奇数GUI宽也按原版顺序舍入。
- 状态行保留彩色包/头/甲、等级和百分比，百分比紧贴图标下方，后接射击模式、装填/备弹、疾跑和恢复。背景画满共享外框，极长数值仅压缩内部内容。
- “其他设置 → 战斗HUD与倒地救援 → 状态栏”新增默认开启的“血条和状态栏与快捷栏等宽”。旧显式240宽设置保留，只有关闭对齐后才采用自定义宽度；无需改正在运行的世界NBT。

## 一次性重置与持久化

本地HUD格式升级到版本2。旧版文件在应用迁移时先备份原文，再清除全部旧位置；只有原生Xaero配置而没有本附属位置文件的安装也执行此次重置。原生地图真正就绪后强制放右下并保存，成功后清除待重置标记。此后新拖动的位置正常保存，不会每次进入都重复重置。

当前实例已写入 `neoforge-1.21.1/run/config/tacz_pubg-hud.json`，内容为版本2、空位置集合、`nativeMapResetPending=true`。原生配置原文备份在 `logs/hud-reset-20261022-072136-827/xaerohud.txt`，重置记录同目录 `reset.json`。未改原生配置中的其他设置，也未改世界数据。

源码修改需通过原启动脚本重新启动客户端；正在运行的冻结快照不会被修改。未擅自启动游戏。
