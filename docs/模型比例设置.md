# 独立模型比例与默认预设

入口：`其他设置 → 模型比例`。

可以分别编辑萌趣世界、像素硬核两种风格的物品比例。页面初始选择当前游戏配置使用的风格；切换编辑风格会保留另一套未保存草稿，不会切换实际游戏风格。一次“保存全部”提交两套完整草稿，并同步至该存档的所有玩家。

- 掉落倍率：0.1–5，作用于空中抛出和落地后的显示、客户端/服务器拾取边界、显示裁剪边界、生成落地时的占地检查。
- 穿戴倍率：0.1–5，作用于背包、伞包、防弹衣和头盔的身体显示。背包/伞包保持背板贴背，防弹衣保持躯干中心，头盔保持头部锚点。
- 设为默认值：立即保存全部草稿，并只把当前编辑风格的当前数值写成这个存档的默认预设。另一风格的默认预设保持。
- 恢复默认：只恢复当前风格到它已保存的默认预设，修改先进入草稿，再按“保存全部”应用。
- 恢复初始 1：只把当前风格的当前倍率改回 1，不删除用户已保存的默认预设，再按“保存全部”应用。

初始两种风格的所有倍率与默认值均为 1。倍率叠加在模型自身的基础尺寸之上；它不会把急救包、医疗箱、饮料或不同背包重新归一化成同样大小。GUI 图标与手持基础尺寸保持各自资源定义。

当前列出 23 种现存物资：三个头盔、三个防弹衣、三个背包、伞包、六种药品、七种投掷物。没有穿戴显示的物品会禁用穿戴输入框。修改必须通过服务端管理员权限和版本检查；同时编辑发生冲突时保留草稿，重新载入需确认放弃未保存内容。

设置保存在存档主世界的 `data/tacz_pubg_model_scales.dat`，包含两种风格的当前值、独立默认预设和修订号。不会修改机器、Codex 或其他存档的配置。

渲染和服务端检查都根据当前风格选择倍率。服务端从随模组提供的精细三角网格/像素模型与 GROUND display 中计算数值边界，使用与地面渲染一致的薄轴放平、水平居中及底部贴地方式；用户倍率作用于这组实际尺寸，固定 2 毫米地面抬升不随倍率放大。原有小型物理载体碰撞箱仍用于原版重力运动。

本轮没有主动启动游戏；数值、保存/同步和编译检查由本轮集成验证记录。
