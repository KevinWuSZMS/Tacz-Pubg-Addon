# 物资使用原生掉落物尺寸

更新日期：2026-10-18。

概率列表里的物品，无论玩家扔出还是 `itemRespawn` 生成，都使用物品本身的原生掉落物尺寸。飞行与落地共用同一个绘制入口，不再因为薄层、弹药、extension、二维模型或图标而额外乘大小系数。

| 类型 | 当前尺寸规则 |
| --- | --- |
| 枪械三维模型 | 保留 baked `GROUND` 变换、枪包 `transform.scale.ground` 和原生定位节点；不额外缩放 |
| 弹药三维模型 | 保留原生 `GROUND` 和枪包弹药 ground scale；不额外缩放 |
| 配件三维模型 | 保留物品自身的 baked `GROUND`；不额外缩放 |
| 普通 baked 物品，包括二维模型 | 调用原生 `ItemRenderer` 的 `GROUND` 显示方式；不额外缩放 |
| 无三维模型的 TaCZ 图标 | 按原生 `SlotModel` 的一格四边形及其物品 `GROUND` 变换计算实际宽深，再平放贴地 |

TaCZ 当前版本的独立配件 `GROUND` 原生 scale 是 **0.5**，这是其原生掉落物尺寸的一部分，仍保留。当前无三维弹药图标为 **1×1** 格，配件图标为 **0.5×0.5** 格。过去统一使用的 `0.6×0.38=0.228` 格图标规则已经取消。

本次保留小碰撞箱、重力、去自旋、抛出方向的小幅随机角度、底面贴地及落地动画衔接。模型贴地只改变平放角度和位置，不改变大小。

数字占地文件更新为 **version 4**，并重算 749 项：424 把枪、78 种弹药、247 个配件，其中 681 项有三维模型，68 项使用图标。加载器拒绝旧版本尺寸文件；客户端资源重载会清空模型与图标测量缓存。

离线核对覆盖全部 749 项的原生尺寸和贴地边界，另完成 50,000 次包络区间及 424 把枪的占地覆盖检查。未启动 Minecraft。枪包已有的一条缺失模型资源仍使用原有图标回退，本次没有新增缺失。

实现入口：`DroppedLootRenderer → GroundLootRenderer.renderStack`。落地后的 `GroundLootEntity` 直接调用同一个 `renderStack`；概率列表的自动识别和实体转换规则没有改变。
