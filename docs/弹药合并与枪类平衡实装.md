# 弹药合并与枪类平衡实装

2026-10-18，Minecraft 1.21.1 / TaCZ NeoForge r7。已按批准的[带图逐枪表](compatibility/ammo-performance-proposal.html)实现为可选方案。未启动客户端、服务器或世界；完成的是构建、源码核对与离线逻辑检查，尚无游戏实测。

## 启用

以 OP 身份打开 `/pubgdebug config → 枪械设置`，分别选择并保存：

| 选项 | 初始 | 实验性调整 |
| --- | --- | --- |
| 子弹 | 每枪原枪包供弹 ID | 420 把固定供弹映射，其中340把改变ID，使用18种现有供弹物品；4把无具体目标保持原弹药 |
| 平衡调整 | 枪包原参数及 TaCZ 原回正 | 386 把采用批准的距离角色目标，13 把重武器采用批准爆破目标，25 把保留先前实验逻辑；延续396把现实参考弹道、28把特殊原弹道及持久峰值后坐力 |

两个开关相互独立：可以只合并供弹，也可以只使用角色平衡。保存后等待服务器“已生效并同步客户端”的通知；选择“初始”从原始资源重新加载，不通过反向倍率还原。瞄具仍独立控制，其他配件实验选项仍只保存选择。

## 供弹规则

普通补给核心为7.62、5.56、9mm、.45与12 Gauge；稀有5.7和.50 BMG承担部分强性能武器；火箭使用现有RPG-7弹药，榴弹保留35/40mm区分。连同特殊保留共18个供弹ID。名称是游戏补给分类，不声称不同现实口径可以直接互换。

固定映射只改变每枪读取的弹药ID，不会因切换射击模式、临时配件或修改DPS而自动重新分类。不删除原物品注册，不自动转换旧背包弹药，不清空或补满已有枪械的已装弹数量。原弹药物品仍存在，但启用映射后装填需使用该枪的新供弹ID；切回初始后重新使用源枪包ID。

`/pubgdebug itemRespawn` 在整存档所有维度的标记区域重新生成物资，未加载部分按既有规则延后。随枪弹药动态读取当前已生效的枪械供弹ID，按基础弹匣容量生成 `ceil(容量 / 30)` 份、每份30发，位置继续使用配置中的随机半径。切换方案不会自动替换已经摆在地上的旧弹药；需要重新执行刷新。物品概率与稀有投放权重不会由本次映射自动改写。

HP以普通难度、护甲前为口径，2HP为1颗心。爆破伤害采用TaCZ原生可见碰撞箱采样与线性衰减；困难难度先乘1.5再结算护甲。地形强度6采用与末影水晶相同级别的射线能量，破坏结果由材质、爆点与随机射线共同决定。

直击的基础伤害与距离表同比缩放，保留阈值和衰减比例；爆头倍率为1、穿甲比例为0、单次命中终结。中心击退冲量上限为榴弹0.6、火箭1.0、PF98 1.2格/tick，再依距离与抗性衰减。实验默认启用破拆，基础设置中逐枪显式选择优先，并遵循TaCZ服务器全局地形开关。每枚弹丸冻结发射资源快照，后续切换方案采用新发射参数。

射速、弹容、装填、弹道和配弹继续采用各自设置；轰炸区使用基础设置中独立的弹丸性质。网页以批准资源的独立副本预览两个方案。研究和批准记录保存在 `logs/heavy-weapon-proposal/`，构建与部署证据在 `logs/heavy-balance-approved/`。

## 角色平衡规则

386把枪的有效伤害、头倍率、瞄准/腰射散布、ADS时间和射速上限采用批准目标。普通步枪、近距冲锋/手枪、多弹丸霰弹、独头弹角色、DMR、慢射精确狙、重型慢射/半自动狙、早期精确枪和机枪分开。13把重武器使用本次批准的爆破目标，25个其他特殊角色保留此前实验分支。

伤害距离表以5米左保持阶梯实现，准确经过10、25、50、100、200、300、500米的批准包络节点；首个距离仍表示完整伤害射程。距离使用TaCZ出生点到命中点的三维直线距离。超过500米沿用末段保留比例，不伪造额外无依据的衰减。

TaCZ的JSON `damage` 是整发基础伤害，原生引擎会按弹丸数量均分到每颗霰弹；实装不重复除以弹丸数。所有射击模式的伤害、头倍率及散布加法增量归零，避免另一模式突破角色边界。各模式只降低射速，连发的串内BPM和整轮间隔也受限；整数毫秒定时器保守量化，所以实装射速可能略低于表内连续目标。例如700RPM上限采用697字段、86毫秒间隔，约697.67RPM。

真实弹匣、换弹、拉栓和其他机械字段保留。既有现实参考初速、距离阻力、9.80665m/s²重力与逐段碰撞沿用，不为了枪类区分把所有狙击枪强行设成比步枪更快。原研究的后坐力控制系数与每发实际峰值持久后坐力保留；角色目标覆盖旧伤害和散布目标，因此不再承诺旧综合难度排名。

108把带Lua的角色枪涉及30份唯一脚本，静态核对没有`calcSpread`或属性修改覆写，原装填/拉栓/`shootOnce`逻辑保留。记录见[脚本审计](../logs/approved-role-script-audit.json)。此结论针对当前安装资产，更换枪包后需要重新核对。

## 数据与验证范围

[HTML](compatibility/ammo-performance-proposal.html)、[CSV](compatibility/ammo-performance-proposal.csv)与[JSON](compatibility/ammo-performance-proposal.json)保留改动前实验数值和批准目标作对照；其中`current`表示旧实验对照，`candidate`表示已批准目标。`applied`表示该条目已实现为可选功能，不表示某个存档已经启用；`inGameVerified=false`明确表示尚未游戏实测。

运行资源为`assets/tacz_pubg/experimental_ammo.json`与`assets/tacz_pubg/approved_role_balance.json`，导出时核对共享数据冲突，枪包源文件保持不变。离线检查覆盖固定映射、全部模式、七个距离节点、浮点霰弹均分与全丸累加、射速上限及初始分支还原；没有将静态检查冒充实际命中率、护甲平衡或多人体验验证。
