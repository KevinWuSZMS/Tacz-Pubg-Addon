# 像素头盔高度与其他设置入口调整

2026-10-22，对应18:23的四张蹲姿对比截图及18:32的设置页截图。

## 像素硬核头盔

高度修正和3.1穿戴倍率仅用于 `pixel_hardcore`。萌趣世界的穿戴倍率、位置、个人默认值保持原有行为。

- 像素硬核一级、二级、三级头盔的初始穿戴倍率统一为3.1，掉落倍率保持独立。
- 只上移像素硬核二级头。一级、三级的安装位置保持不变。
- 四张截图中，中央头顶区域的冠顶约为：三级680像素、二级707像素、一级675像素，未戴头盔约713像素。二级比另两种低约27至32像素。
- 使用模型顶点和 `FIXED` 变换校准后，在3.1倍率下，一级、三级模型顶点的头部局部高度分别约0.65708、0.64371格，二级原为0.53023格。二级应提高约0.12017格才能接近两者平均高度。
- 实际修正为 `0.90 × 穿戴倍率 × 0.043` 格；倍率3.1时提高0.11997格。修正随穿戴倍率同步缩放，头部旋转和蹲姿由原头部姿态继承。

不修改模型资源、手持显示或掉落显示。穿戴位置通过渲染层单独校正。

模型比例存档格式从1升级到2。旧格式首次读取时，将当前像素硬核三种头盔穿戴倍率统一到3.1，保留掉落倍率、其他物品和萌趣世界设置；原始格式1数据同时保存在 `previous_schema1` 中。完成迁移后，管理员后续自行修改的值正常保存，不会每次载入都重置。网络设置通道同步升级，避免旧版客户端错误理解新的稀疏默认值。没有直接改写正在运行的世界数据文件。
