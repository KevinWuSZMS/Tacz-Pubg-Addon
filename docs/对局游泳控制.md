# 对局游泳控制

2026-11-17 按用户提供的 PUBG 按键图实现，作用范围为对局参与者。

## 按键与姿态

| 操作 | 复用的对局按键 | 默认 |
| --- | --- | --- |
| 移动 | 原有前后左右 | W A S D |
| 下潜 | 对局蹲下键，按住生效 | C |
| 快速游泳 | 对局冲刺键，向前移动时按住生效 | 左 Shift |
| 上浮 | 当前跳跃键，按住生效 | Space |

改键后游泳跟随当前绑定，包括组合键和鼠标绑定。上下同时按住时抵消手动升降；明确上浮或下潜时，镜头俯仰不反向覆盖该指令。进入游泳清除地面蹲／趴切换状态及自动跳跃残留，按住冲刺出入水面可继续衔接地面冲刺和快泳。菜单、覆盖界面或窗口失焦时不接收游泳操作。

水深以玩家 XZ 所在的连续可通行水柱厚度为准，与实际站立身高比较。达到或超过该身高即进入游泳，触底或未按冲刺也一样；使用站立尺寸避免游泳后碰撞箱变矮造成判断抖动。缩放玩家按缩放后的身高判断，流水高度及含水半砖、台阶、栅栏等支撑碰撞形状参与计算。检测达到阈值即可停止，不会扫描整片水域。

浅水触底时保留对局地面站立、蹲下、冲刺等行为；离开支撑、仍在水中时使用游泳控制。浅水站在方块上可以探头，水中游泳姿态禁止探头；陆地趴下探头继续保留。

对局参与标记通过实体数据同步给其他客户端。离开对局、死亡、换维度、重生等会释放控制；倒地、救援、飞行、骑乘和空中跳伞继续使用已有规则。游泳复用原生水中移动、阻力与碰撞，没有新增对局计时。
