# 对局游泳控制

2026-11-17 按用户提供的 PUBG 按键图及两段录像反馈实现，作用范围为对局参与者。本次修订采用用户明确指定的固定 1.5 格阈值，替代上一轮按站立身高判定的规则。

## 按键与姿态

| 操作 | 复用的对局按键 | 默认 |
| --- | --- | --- |
| 移动 | 原有前后左右 | W A S D |
| 下潜 | 对局蹲下键，按住生效 | C |
| 快速游泳 | 对局冲刺键，向前移动时按住生效 | 左 Shift |
| 上浮 | 当前跳跃键，按住生效 | Space |

改键后游泳跟随当前绑定，包括组合键和鼠标绑定。游泳方向只随视角左右转向，抬头、低头不产生升降推力。上浮和下潜只由对应按键控制，上下同时按住时抵消；松开后清除旧的垂直动量，避免惯性、碰墙跳起或原生重力残留持续改变深度。保留原生水中升潜推力、阻力和水平移动。菜单、覆盖界面或窗口失焦时不接收游泳操作。

水深以玩家中心 XZ 所在的连续可通行水柱厚度为准：小于或等于 1.5 格不进入游泳，大于 1.5 格强制游泳，是否触底、冲刺、跳入或缩放均不改变阈值。读取实际流水高度及含水半砖、台阶、栅栏等支撑碰撞形状，不把所有水方块都算作完整一格。检测达到阈值即可停止，不会扫描整片水域。

浅水使用直立慢行，复用现有 WALK／潜行速度属性及原生水阻力；清除蹲下、趴下、冲刺和自动跳跃，不能靠在开放浅水中连续跳跃规避惩罚。朝更高且有站立空间的可达岸面移动时，空格允许爬出；普通台阶继续可通行。浅水站在方块上可探头和开火，中心已上岸而身体边缘擦水不会继续锁定慢行。低矮顶棚仍保留碰撞必要的降低姿态，避免身体穿过方块。

深水泳姿禁止探头、枪械开火、蓄力和瞄准。服务端在上膛或扣弹前拒绝射击请求，并终止入水前排队的剩余连发；客户端同步取消瞄准和整组连发反馈，出水不会恢复旧组的枪声、动画。陆地趴下、浅水和非对局枪械行为保留。

持续上浮时，在实际移动前限制高度，让身体保持浸水、眼睛露出水面呼吸；已有泳姿允许极短的水面接触间隙，避免直立和游泳反复切换。近岸原地按空格仍维持水面限制，朝可达岸面移动时才放行爬出。真正上岸恢复地面控制，持续按住冲刺可衔接地面冲刺。

对局参与标记通过实体数据同步给其他客户端。离开对局、死亡、换维度、重生等会释放控制；倒地、救援、飞行、骑乘和空中跳伞继续使用已有规则，没有新增对局计时。
