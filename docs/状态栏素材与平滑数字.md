# 状态栏素材与平滑数字

状态栏改用参考截图生成、提取的透明图片，以及真实 Bebas Neue 字体的抗锯齿字形贴图。

- 0–3 级背包、头盔、护甲：将用户后四张截图中的三个图标裁成参考网格，使用内置 imagegen 重生成。用户同意对生成结果自动清边后，按中性灰前景恢复透明度、去除背景杂点，导出白色遮罩；没有手工绘制装备轮廓。
- 疾跑、回血与肺：从第一张截图直接裁取，没有重新绘制。疾跑估算局部背景恢复透明度；回血与肺根据原图像素边缘提取完整轮廓、填实内部，避免背景阴影造成图标缺块。回血十字的透明度左右、上下对称校正。原始图标只有约 30–40 像素高，保留其细节上限。
- 状态栏按左三项（背包、头盔、护甲）、中三项（射击模式、当前弹药、备用弹药）、右三项（疾跑、回血、氧气）排列。当前弹药按实际可见字形中心对齐整条及默认物品栏中心，位数变化不会向右偏；长数字和窄屏按比例适配。肺下面显示玩家氧气量／最大氧气量的百分比，满氧显示 100%，水下或缺氧时图标点亮，氧气不超过 25% 时数字变红。
- 数字：使用 Google Fonts 官方仓库的 Bebas Neue Regular，随资源保留字体文件与 SIL OFL 1.1 授权。截图没有提供原始字体文件，因此这是接近参考图的窄体替代字体，不能声称与原字体完全相同。
- 全部图片使用透明 PNG 和线性过滤。数字覆盖弹药、备用弹药、∞、装备等级/百分比、武器栏数字及动作倒计时；真实状态栏与 HUD 布局预览共用渲染路径。

## 文件

运行资源位于 `neoforge-1.21.1/src/main/resources/assets/tacz_pubg/textures/gui/hud/`；装备与状态符号在 `status/`，数字在 `numbers/`。每个目录保存了来源、哈希或字形尺寸记录。字体与授权位于 `assets/tacz_pubg/font/hud/`。

`docs/repository/status-bar-assets/` 保留参考网格、原始状态栏截图、被选中的 imagegen 原图、最终提示词 `imagegen-final-prompt.txt` 及素材预览 `preview.png`。预览是素材展示，不是游戏截图。

`hud-alignment-preview.png` 展示新状态栏在 6／19／100 发弹药及 100%／72%／25% 氧气下的静态布局，蓝线标出默认物品栏中心；该图不代表客户端实测。

## 重建

使用安装 Pillow 与 numpy 的 Python，从仓库根目录运行：

```text
python scripts/prepare-status-equipment.py
python scripts/extract-status-symbols.py
python scripts/build-hud-number-atlas.py
```

前两步处理已有素材，第三步从随附真实字体栅格化字形。无需再次调用 imagegen，也不需要 API key。数字字形尺寸记录与 `CombatHudNumbers` 常量必须一起更新。

## 验证边界

编译、现有装备布局检查和资源打包检查可以确认引用、尺寸、透明度、字形及包内文件；它们不等同于游戏内实际渲染验证。实际效果仍需在客户端查看 F8 预览，以及比赛中的装备切换、弹药变化、疾跑、回血、氧气变化和救援倒计时。
