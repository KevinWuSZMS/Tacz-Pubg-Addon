# 背包容量基线

本模组按每个物品的 PUBG PC `Inventory space` 计算容量，堆叠数量与每个容量相乘。2026-11-17 核对 [PUBG Database](https://pubg.gs/) 的普通模式物品，页面版本为 Update 44.1、Steam build 26563649，提取日期 2026-11-11。活动模式和同名特殊变体不进入默认值。

本次仅调整背包容量；药品的使用时间、回血预算与分次治疗继续采用项目约定的 42.1 基线。管理员已保存的单物品容量覆盖值继续优先。

## 装备与总容量

保留现有基础容量 70；穿戴防弹衣增加 50，一级／二级／三级包增加 150／200／250，最高总容量为 370。背包和护甲的加成已与[Gear](https://pubg.gs/gear/)核对。基础 70 为项目既有值，两站未直接列出基础容量；[官方 28.2 公告](https://www.pubg.com/en/news/7083)确认腰带容量并入基础容量。

| 未穿戴装备 | 每个容量 |
| --- | ---: |
| 一级／二级／三级头盔 | 40／50／60 |
| 一级／二级／三级防弹衣 | 120／150／180 |
| 任意等级背包 | 400 |

穿戴槽内的装备不计上述散装占用。背包 400 是数据库的物品占用字段，并非背包加成，因此默认规则下无法存放一个备用背包。换包时若旧包无法放回物品栏，则落到玩家身旁；其余物品超出新背包容量时仍拒绝降级。地面装备走直接穿戴／替换流程。

指定近战槽只对实际近战物品免容量，包含原生 LR 近战武器；药品临时借用该槽仍计量。鼠标拿起的物品、临时合成输入、容器和收纳袋里的物品继续计入容量。容量采用千分之一整数运算，界面显示最多三位小数，不再把 0.35 显示成 0.4。普通 MC 物品保持每个 1 的适配值。
