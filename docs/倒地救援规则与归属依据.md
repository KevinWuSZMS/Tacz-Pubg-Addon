# 倒地、救援和战斗归属

2026-10-22。实现对象为真实对局真人与 Carpet 玩家。这里区分官方已明确的信息、用户指定规则与 Minecraft 可调适配。

## 官方依据

- [PUBG 15.2 官方补丁](https://pubg.com/en/news/1725?category=patch_notes)：倒地进入保护期1.5秒；当时第1至9次倒地流血时长依次90/30/30/10/7/5/4/3/2秒；普通伤害按三级护甲处理，SR与弩按真实护甲并另增伤；破片对倒地伤害额外降低20%。代码将这些作为移动状态初始参数，均可调整。
- [PUBG 23.2 官方补丁](https://www.pubg.com/en-asia/news/6292)：静止时自动失血速率不随倒地次数变化，移动和水中有区别。只转视角不应当作爬行。本模组静止默认90秒，为可配置适配，不声称该补丁给出了90秒数值。
- [PUBG 14.2 官方补丁](https://pubg.com/en/news/1735)：倒地可在水中慢速移动；不重置空气；不能水下救援，双方任一入水下会中断救援；浮在水面可以救援。代码保留原版空气/溺水损伤，增加可配置连续水下10秒上限。
- [PUBG 12.2 官方补丁](https://pubg.com/en/news/1737)：Self AED 是全队全倒和单排倒地的特殊例外。本模组没有该物品，因此无在线可行动同队者时直接淘汰，全队失去行动能力时结束其倒地成员。
- [PUBG 11.1 官方补丁](https://pubg.com/en-asia/news/1368)：击倒与爆头图标应分开，不能用单一状态覆盖另一状态。

这些历史补丁给出规则变化的原始证据，并不等于已证实2026所有模式和特殊装备的统一参数。未引入AED、召回、搬运和特殊医疗装备。

## 明确的可配置适配

救援200游戏刻、复苏30%最大生命、3方块距离、0.35方块移动容差、救援时暂停自动流血、静止90秒、陆地爬速乘0.18、助攻1200刻窗口与1点PUBG伤害阈值是管理员可调整默认值。其中救援时长和复苏生命未在此次取得同等级官方明确数值，不伪称已核实。倒地动作先用原版趴姿占位，不是PUBG专用倒地动画。

倒地用独立HP池（默认100）；宿主实体保持1点生命，仍为真实存活，不能掉装备或进入旁观。普通20最大生命时伤害按5倍换算；最大生命改变时按100/实际最大生命归一。枪伤、爆炸、环境伤害和流血最终都能淘汰，不能靠恢复血量无限免死。倒地保护期默认30刻。服务器限制水平爬速并禁止跳跃；水中允许慢游，不补空气。

救援使用现有共用交互键，再按一次或按实际取消使用键中断。服务端逐刻检查同队、存活、倒地状态、同维度、距离、视线、朝向、双方位置、救援者选槽/用药/冲刺/载具/飞行/界面和水下状态；接受伤害会中断。已淘汰或真正死亡者不可能被该救援接口复活。对局暂停冻结进度、失血和保护期。离线、换维度取消救援；倒地离线按最终淘汰处理；结束、重连、换世界清理临时姿态和操作状态。

生命周期复核：倒地者抵达其他维度时沿既有越界的行政淘汰路径结算，保留原击倒者归属，清除倒地/救援与爬速；不会在新维度补造一次实体死亡、掉落比赛装备或创建死亡观战锚点。正常补杀、流血与倒地离线仍走真实死亡。手动结束和自然结束均同步结算最后的边界淘汰并清理姿态/操作快照，服务器刻循环另保留兜底清理。

## 归属（用户要求优先）

- 同队成员补杀其队友击倒的敌人：击倒者获得淘汰，补杀者获得助攻。
- 不同敌队补杀：补杀者获得淘汰；原击倒队伍不会因第三方补杀获得助攻。
- 流血、蓝圈、全队失去行动能力、倒地掉线等无新敌方补杀者的完成：有效敌方击倒者获得淘汰。
- 无击倒者的环境、越界、掉线淘汰：无正向淘汰归属。友伤不产生正向淘汰或助攻。
- 其余助攻只授予最终获淘汰队伍中、在窗口内达到实际伤害阈值的其他成员。按同一最终淘汰去重；救起后清除上一次受伤账本。

TaCZ枪械普通/AP分段使用真实伤害事件记录；爆头与枪械ID在伤害前关联DamageSource，最终结算在MatchService实际死亡入口完成，不依赖在死亡之后才发布的TaCZ GunKill事件，也不依赖客户端加载目标实体。

## 接口与验证

`CombatPayloads` 的 Snapshot/Event/Rescue 为会话、序号、语义、身份与权威统计；Event以EventMessage内部包装避免与原生payload的type方法冲突。敌方仅同步倒地标记，不传其倒地生命。全局队号来自冻结房间队伍；颜色读取管理员 `PubgSettings.teamColor`，和本队成员的六色序号独立。

新增 `CombatRulesChecks` 与 `CombatWireChecks`，覆盖用户两种补杀规则、友伤/环境/助攻边界、流血预算、救援条件、队号及实际网络编解码。本代理按主代理约束未运行Gradle或游戏；主代理统一集成检查。离线检查不等于多人实机验收。
