# 未开伞阶段的非线性速度与视角

本轮只调整跳机后、开伞前的自由落体阶段。真实玩家继续由本机客户端计算运动，服务器接收玩家移动并处理碰撞；Carpet 人机使用相同算法在服务端计算。已开伞运动、开伞条件和状态机沿用现有逻辑。

## 速度口径

速度 HUD 读取三维位置变化，显示的是完整速度向量的长度。因此这次标定是：

- 平视并持续前进：三维稳态速度 **126 km/h = 35 m/s**。
- 垂直俯冲：三维稳态速度 **234 km/h = 65 m/s**。
- 平视前进采用 1:1 的水平距离/下降高度比：水平与下落各约 **89.10 km/h = 24.75 m/s**，合速度是 126，不是把 126 水平速度再叠加额外的高速下落。
- 不按方向键时，平展姿态仍以 126 km/h 的稳态速度竖直下落；方向输入把一部分下落运动转成水平运动。

126 与 234 是用户指定的游戏标定值；中间角度、升阻系数和姿态响应是本项目的实现，不代表 PUBG 官方公开过相同公式。

## 算法依据

[NASA 阻力方程](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/drag-equation/)给出阻力与空气相对速度平方的关系，形状、姿态和参考面积都影响阻力系数。[NASA 升力方程](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/lift-equation/)同样使用速度平方；[NASA 滑翔角说明](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/glide-angle/)解释了滑翔仍会失去高度，水平与下降运动是同一个三维飞行过程。

把空气密度、参考面积及玩家质量吸收到系数后，每个积分步采用：

```text
a = (0, -g, 0) - kD × |v| × v + kL × |v|² × n
```

其中 `n` 是把方向输入投影到实时速度的垂直平面之后得到的单位向量。阻力反向作用于现有三维速度；升力垂直于该速度，只改变方向，不提供额外动能。水平朝向只旋转输入方向，不改变同一姿态的稳态速度。

`g` 使用 Minecraft 原本 `0.08 格/tick²` 对应的 `32 m/s²`；这是一格按一米换算后的游戏重力，不是地球重力实测值。

### 端点标定

设平视总速 `VF=35`、垂直俯冲总速 `VD=65`，方向输入强度为 `u∈[0,1]`：

```text
kF = g / VF²
kDive = g / VD²
kLFlat = kF × u / √2
kDFlat = √(kF² - kLFlat²)
```

这保证平视时 `√(kDFlat² + kLFlat²)=kF`，不同输入强度都保持同一 126 km/h 总速端点，而是改变水平/下落的分配。满方向输入时升阻系数相等，对应 1:1 滑翔比。

俯视角 `θ` 限制在 `0°–90°`；疾跑/俯冲键采用直俯冲姿态。用 `cos²θ` 表示展体姿态的投影权重：

```text
kD = kDive × sin²θ + kDFlat × cos²θ
kL = kLFlat × cos²θ
```

这些角度函数改变受力系数；随后积分加速度得到速度，不按角度线性插值目标速度。稳定下降时，力平衡给出独立校验式：

```text
R = √(kD² + kL²)
V = √(g / R)
水平分量 = V × kL / R
下落分量 = V × kD / R
```

## 满方向输入的稳态结果

| 俯视角 | 水平 km/h | 下落 km/h | HUD 合速度 km/h |
| --- | ---: | ---: | ---: |
| 0° | 89.10 | 89.10 | 126.00 |
| 15° | 90.22 | 92.88 | 129.49 |
| 30° | 92.88 | 105.58 | 140.62 |
| 45° | 93.24 | 131.47 | 161.17 |
| 60° | 78.43 | 174.91 | 191.69 |
| 75° | 32.76 | 219.83 | 222.25 |
| 90° | 0.00 | 234.00 | 234.00 |

45° 的合速度是约 161.17，明显不同于两端速度线性平均得到的 180。中段水平分量可略高于完全平视，因为收体同时降低阻力；更深俯冲时升力减小，速度逐步转为垂直分量。

每个游戏 tick 分为四个固定子步积分，以减少高速转向和姿态变化时的数值误差。俯冲转平飞会先保留惯性，再由较大阻力减速；平视的 126 是稳态值，改变姿态不会把当前速度瞬间改写成终速。游戏包络限制三维总速不超过 234 km/h，并保留持续下落，包络只移除额外动能。
