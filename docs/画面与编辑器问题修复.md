# 画面、编辑器与对局操作修复

## 像素物品的闪烁白点

像素物品的贪心合并面存在 T 接点：较小面的端点落在相邻长边中间，相邻面没有一致的边分段。投影时极细的裂缝会随视角变化；选中物品的原版白色描边进一步放大了这些孔缝。抽查医疗箱、急救包、防弹衣、头盔和烟雾弹，使用中的贴图区域均完全不透明，未发现贴图透明针孔。原模型还未声明渲染层，会落入透明混合层。

修复覆盖目前接入的 20 件源模型物资：沿已有共边顶点三角剖分，再把可合并的相邻三角形配回四边形，资源加载时一次烘焙为普通缓存模型。显式使用裁切渲染层，细分面之间不再各自收缩 UV。轮廓、体素密度、原始 elements、贴图、显示比例和萌趣模型均保留，未修改伞绳距离档位。

实际提交四边形由 26,527 增至 37,599，增幅约 41.74%；这是封缝的几何开销，未偷偷降低精度。逐条检查实际三角形边、面积、方向、覆盖和 UV 等价性；备份及报告位于 [pixel_seam_repair](../model-workflows/output/pixel_seam_repair/installation.json)。源码 C4D 与原始导出档案保持原样，后续像素导出也使用同一修复流程。

## 配置与声音

切换萌趣世界后保存失败的原因，是原生 PUBG 投掷物实现 LR 动画接口后，被配置目录误当成必须指定额外资产 ID 的通用壳。现在按默认物品是否已有固定 LR 身份区分，七种独立注册投掷物可以正常作为普通物品保存。

普通蓝圈和蓝圈手雷扣血均关闭受击音效，同时覆盖服务器播放与客户端伤害事件播放路径；实际扣血、同步及其他伤害来源继续执行原逻辑。

主手拿药品时，按当前绑定的拾取／交互键开始使用；单按即可完成原有持续用药流程，主手右键不再开始用药。换槽、取消、移动限制、75% 生命值上限和局外效果继续执行药品规则；客户端与服务器通过请求确认保持一致。

每张地图记录成功开局时实际使用的规则，重新创建时默认预选；保存草稿不会改写上一局记录。已有草稿和手动选择优先，规则改名跟随，规则删除与地图删除安全清理，旧存档兼容。

## 编辑界面

HUD 编辑器进入时即关闭模糊、菜单底纹和全屏遮罩，直接显示正常游戏场景。仅保留角落 ESC 提示，按 ESC 显示保存并退出、不保存并退出、继续编辑、恢复初始位置。详见 [HUD 布局编辑](HUD布局编辑.md)。

2026-10-22 00:06:33 的投掷物编辑器崩溃，由未注册的 `screen.tacz_pubg.throwable_settings.field.area_cloud` 标签触发。字段标签改为可回退的原生文字组件，已知 LR 字段补齐中英文，未知扩展字段显示完整路径；不会在绘制时因未知翻译键退出。

## 自由落体

未开伞阶段改为三维二次阻力和升力积分，视角改变姿态系数，水平朝向控制转弯，保留惯性。以速度 HUD 的三维总速标定平视 126 km/h、垂直俯冲 234 km/h，45° 稳态约 161.17 km/h。公式、分量、参考来源与适用范围见 [非线性速度模型](跳伞自由落体非线性速度模型.md)。

本说明的几何与逻辑验证不替代实际游戏画面验收；本轮不主动启动游戏。
